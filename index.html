손글씨 폰트 만들기

종이에 쓴 손글씨를 사진으로 찍어 올리면 윈도우에 설치할 수 있는 .ttf 폰트가 됩니다. 프로그램 설치도, 회원 가입도 필요 없습니다.

🔒 사진은 이 브라우저 안에서만 처리됩니다. 서버로 올라가지 않습니다.

1 양식을 인쇄합니다

인쇄할 종이: —

  • A4 · 실제 크기(100%) 로 인쇄하세요. ‘용지에 맞춤’ 을 끄면 됩니다.
  • 연한 파란 글자를 따라 검은 볼펜이나 사인펜으로 크고 진하게 씁니다.
  • 칸 밖으로 나가지 않게, 옆 칸과 겹치지 않게 씁니다.
  • 한글 자모 칸은 연한 파란 사각형을 꽉 채우도록 쓰면 글자가 예쁘게 조합됩니다.
  • 연필은 너무 흐려서 잘 인식되지 않습니다.

2 사진을 올립니다

📷
사진을 여기에 끌어다 놓거나 눌러서 고르세요
여러 장을 한꺼번에 올려도 됩니다 · JPG 또는 PNG
  • 종이 네 모서리의 검은 사각형이 사진에 모두 보여야 합니다.
  • 그림자가 지지 않게, 밝은 곳에서 위에서 내려다보며 찍으세요.
  • 스캐너로 스캔하면 가장 정확합니다.
  • 같은 쪽을 여러 번 찍어 올리면 더 잘 나온 쪽이 자동으로 선택됩니다.
  • 아이폰이라면 설정 → 카메라 → 포맷 → ‘높은 호환성’ 으로 두면 확실합니다. (HEIC 사진은 브라우저가 열지 못합니다.)

    3 폰트를 만듭니다

    윈도우에 설치하는 방법
    1. 내려받은 .ttf 파일을 더블클릭 합니다.
    2. 창 위쪽의 [설치] 버튼을 누릅니다.
    3. 한글·워드·파워포인트를 껐다가 다시 켜면 글꼴 목록에 나타납니다.
    4. 글꼴 이름은 위에서 정한 이름으로 찾으면 됩니다.

    마음에 안 드는 글자가 있으면, 그 칸만 다시 써서 사진을 올린 뒤 폰트를 다시 만드세요. 같은 칸은 더 진하게 쓴 쪽이 선택됩니다.

    모든 처리가 브라우저 안에서 이루어집니다 · 소스와 사용법은 저장소의 README 를 보세요.
